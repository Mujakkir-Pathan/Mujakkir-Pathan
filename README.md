---

I build and run the infrastructure behind software: CI/CD pipelines, Kubernetes clusters, and the Terraform and shell scripts that tie them together. Most of my time goes into AWS, Docker, Kubernetes, Terraform, Ansible, and bash.

I learn by shipping. My repos are full projects worked end to end, from provisioning a cluster to putting ArgoCD and a security scanning stage in front of a deploy. When something breaks, the fix is in the next commit.

## Featured projects

**[AI-BankApp-DevOps](https://github.com/Mujakkir-Pathan/AI-BankApp-DevOps)** `Terraform` `EKS` `ArgoCD` `Helm`

Three tier AI banking app. Terraform provisions the EKS cluster, ArgoCD keeps it in sync with git, and the pipeline blocks on SAST, secret scanning, Sonar, and Trivy before a deploy goes out.

**[U2Collab](https://github.com/Mujakkir-Pathan/U2Collab)** `React` `Node` `MongoDB` `EKS`

Real time workspace with a shared document editor, whiteboard, and team chat. OAuth on the front door, the same GitOps setup on EKS, and a DevSecOps pipeline behind it.

**[devboard](https://github.com/Mujakkir-Pathan/devboard)** `React` `Go` `Postgres` `OpenTelemetry`

Ticket tracking with an AI assistant that streams task summaries. Runs on Docker Compose locally, with a Terraform and ArgoCD path to EKS when it is ready to grow.

**[90DaysOfDevOps-By-Me](https://github.com/Mujakkir-Pathan/90DaysOfDevOps-By-Me)** `Linux` `AWS`

My notes from the 90 days of DevOps challenge: daily tasks, write ups, and the scripts that got them done.
